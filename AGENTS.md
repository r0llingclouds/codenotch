# Project continuity

Before continuing development, read the [Codenotch Project](https://github.com/users/r0llingclouds/projects/11),
the relevant issue, and the current baseline in [docs/personal-widgets.md](docs/personal-widgets.md).
Issues hold task context; Project fields hold status and order. Keep continuation
context there rather than creating a parallel local task ledger.

Use the global `version-control` skill for development and preserve concurrent
work. The personal fork is `r0llingclouds/codenotch`; `vinzdg/codenotch` is upstream.
